# COMPLIANCE COPY LIBRARY V1

更新日：2026-08-26 JST
対象：Firm / Platform / Payout / Article / Campaign / Review / Case Study
位置づけ：公開文言の共通ライブラリ。法的助言ではなく、誤認防止とDisclosureのための運用標準。

## 1. 共通情報免責
`本サイトは、プロップファームや関連サービスについて一般的な情報を整理・比較することを目的としています。掲載内容は個別の投資判断、利益、合格、出金等を保証するものではありません。ルール・価格・利用可能地域・キャンペーン・サービス内容は変更される場合があります。購入・登録前に必ず各事業者の最新の公式情報をご確認ください。`

## 2. Affiliate Disclosure
`PR / アフィリエイトリンクを含みます。当サイトは、リンク経由の申込み等により報酬を受け取る場合があります。アフィリエイト条件は、事実確認、検証結果、診断順位を変更するものではありません。`

CTA近傍の短縮版：
`PR｜このリンク経由の申込み等で当サイトが報酬を受け取る場合があります。`

## 3. Test Account Disclosure
`本検証では事業者からテスト用口座の提供を受けています。口座提供は肯定的な評価や掲載を条件とするものではありません。`

## 4. Sponsor Disclosure
`本コンテンツにはスポンサー関係が含まれる場合があります。スポンサー関係と、事実確認・問題点の記載・編集判断は分離して扱います。`

## 5. Japan Eligibility / Regulatory Separation
`日本からの利用可否に関する表示は、当該サービスの日本における金融商品取引業その他の登録・認可を意味するものではありません。利用前にサービス内容と適用法令をご自身で確認してください。`

## 6. Status / Freshness
`情報確認日：YYYY年MM月DD日。サービス内容は変更される場合があります。`

conditional：
`条件付き・追加確認が必要な項目があります。該当箇所は最新の公式情報を確認してください。`

unknown：
`現時点で十分な確認根拠がなく、情報不足・不明として扱っています。`

## 7. Platform Disclaimer
`同じ取引プラットフォームでも、Firmごとに利用可能な機能、銘柄、市場データ、約定環境、口座仕様等が異なる場合があります。Firm側の最新仕様もあわせて確認してください。`

## 8. Payout Disclaimer
`掲載している出金方法・受取サービス・出金経路は、利用可否、手数料、対応地域、ネットワーク、本人確認条件等が変更される場合があります。送金・出金前にFirmおよび各サービスの最新条件をご確認ください。`

Crypto追加注意：
`暗号資産送金では、対応ネットワークや送付先を誤ると資産を失う可能性があります。表示内容だけで判断せず、送金前に双方の対応ネットワークとアドレス条件を確認してください。`

## 9. Campaign Disclaimer
`キャンペーンは期間・対象・併用条件等が変更または終了する場合があります。通常価格・恒久条件とは分離して掲載し、最終条件は公式購入画面で確認してください。`

## 10. Review / Case Study Disclaimer
`掲載している検証結果や利用者の感想は、特定条件下の結果・意見であり、すべての利用者に同じ結果を保証するものではありません。`

Case Study因果表現：
- 許可：`施策実施期間中に○件を記録`
- 原則禁止：`当方の施策により必ず売上が増加した`

## 11. 禁止表現
原則使用しない：
- 必ず稼げる
- 絶対に出金できる
- 確実に合格
- リスクなし
- 元本保証
- 利益保証
- 誰でも勝てる
- 絶対おすすめ
- 安全なFirm

根拠なしで使用しない：
- No.1
- 日本一
- 世界最大
- 最安
- 最速
- 最も人気
- 信頼性No.1

## 12. Implementation Rule
Disclaimerをフッター1箇所だけに置いて全Disclosureを代替しない。

Affiliate / Sponsor / Test Account等は該当CTA・Contentの近くでも明瞭に表示する。

## 13. Human Review
金融・法的性質の断定、規制当局登録、税務、個別投資判断等を扱う場合は、必要に応じて専門家確認をProduction Gateへ追加する。
