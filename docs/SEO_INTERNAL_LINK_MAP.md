# SEO_INTERNAL_LINK_MAP

更新日：2026-08-17
対象：プロップファームの歩き方
目的：基礎講座・ルール解説・ファーム詳細・診断を孤立させず、検索流入から自然に次の理解へ進める。

## 0. 基本思想

内部リンクは購入誘導ではなく、理解の順番を作るために使う。

基本導線：

`検索記事 → 関連する基礎講座/ルール記事 → ファーム詳細 → 30秒診断 → 必要な場合だけ価格/特典`

価格・クーポンは途中の主役にしない。

---

01 → 02 → 03 → 04 → 05 → 30秒診断

各ページ末尾には「次に何が分かるか」を1文で予告してからCTAを置く。

## 2. Rule Cluster A｜損失ルール

### Hub候補

「プロップファームの最大ドローダウンとは？」

### 子記事

- `/articles/prop-firm-max-drawdown`
- `/articles/static-drawdown`
- `/articles/trailing-drawdown`
- `/articles/eod-drawdown`

### 推奨リンク

最大DD → Static / Trailing / EOD へ分岐。

Static / Trailing / EOD → 最大DDへ戻す。

すべての記事から：

- 基礎講座03「まず確認する3つ」
- 基礎講座04「失格しやすいルール」
- ルール比較
- 30秒診断

へ接続する。

### Anchor例

- 「最大損失の基本から確認する」
- 「固定型のDDを詳しく見る」
- 「残高に追随するDDを詳しく見る」
- 「EOD基準の考え方を見る」

同じ完全一致Anchorを全ページで連打しない。

## 3. Rule Cluster B｜取引制限

### 記事

- `/articles/news-trading-rules`
- `/articles/weekend-holding-rules`
- `/articles/prop-firm-disqualification-rules`

### 推奨リンク

ニュース取引 ↔ 週末持ち越し

両方 → 失格ルール記事

失格ルール記事 → 最大DD / ニュース / 週末へ分岐。

ファーム詳細の「注意したいルール」から、一般解説へリンクしてよい。

一般解説から特定ファームを順位付けしない。

---

## 4. Rule Cluster C｜進行・出金

### 記事

- `/articles/minimum-trading-days`
- `/articles/prop-firm-payout-rules`
- `/articles/prop-firm-free-trial`

### 推奨リンク

無料トライアル → 最低取引日数 → 出金条件

出金条件 → ファーム詳細のPayout欄

最低取引日数 → 基礎講座03

無料トライアル → 基礎講座02「いきなり購入しなくていい」

---

## 5. ファーム詳細からの記事リンク

各ファーム詳細は一般解説記事へ最大3本程度。

例：

- DD方式に特徴がある → Static / Trailing / EODの該当記事
- News条件が重要 → ニュース取引記事
- Weekend条件が重要 → 週末持ち越し記事
- Payout条件が複雑 → 出金条件記事
- Free Trialあり → 無料トライアル記事

全記事を毎社に機械的に貼らない。

ファーム詳細の主役はその会社・プラン情報であり、関連記事は補助。

---

## 6. 記事からファーム詳細へのリンク

一般解説記事では、特定ファームを「おすすめ順」に並べない。

リンクする場合：

- 実例としてルール方式が明確
- SourceHealthがVerified相当
- 公開前に最新公式情報を再確認

を満たすものだけ。

SourceHealth競合中・HOLD中のプランは、確定例として使わない。

---

## 7. 診断へのCTAルール

### CTA前の予告

悪い例：

`今すぐ診断する`

推奨：

`ここまで分かったら、次は自分の条件に合うプランを3つまで絞れます。`

CTA：

`30秒診断で候補を絞る`

### 表現

- 「最強」禁止
- 「ランキング1位」禁止
- 「あなたとの相性」で統一
- Affiliate / coupon / priceを理由にしない

---

## 8. Breadcrumb推奨

### 基礎講座

Home > 初めての方へ > 記事名

### ルール記事

Home > 記事 > ルール解説 > 記事名

### ファーム詳細

Home > ファーム一覧 > Firm名

### プラン詳細

Home > ファーム一覧 > Firm名 > Plan名

Breadcrumb内に価格・セール文言を入れない。

---

## 9. Title重複防止ルール

### 基礎講座

`{テーマ}｜初めてのプロップファーム｜プロップファームの歩き方`

すべてのページを「プロップファームとは？」のような同一Titleにしない。

### ルール記事

`{検索テーマ}とは？{初心者が知りたい補足}｜プロップファームの歩き方`

### ファーム詳細

`{Firm名}の特徴・プラン・注意ルール｜プロップファームの歩き方`

### プラン詳細

`{Firm名} {Plan名}のルール・利益目標・最大損失｜プロップファームの歩き方`

価格はTitleの恒常要素にしない。

---

## 10. Meta Description重複防止

各ページは次の3要素のうち最低2つを固有化する。

- 誰向けか
- 何が分かるか
- 次に何を判断できるか

ファーム詳細では「日本語対応・無料トライアル・プラン・注意ルール」等を会社ごとに組み替える。

すべてのページに同じ160字テンプレをコピーしない。

---

## 11. Canonical

- 各記事は自己canonical
- パラメータ付きURLをcanonicalにしない
- Affiliate / referral URLをcanonicalにしない
- 同一内容を複数Slugで公開しない
- 旧URL移行時はredirect + canonical整合を確認

---

## 12. Sitemap優先順位

優先掲載：

1. Home
2. Beginner Guide Hub
3. Beginner Guide 01〜05
4. Diagnosis
5. Firm List
6. Firm Detail 14社
7. Rule/SEO Articles

Plan Detailを大量生成する場合も、未確認・Legacy・薄い内容のページを無条件にindexさせない。

---

## 13. 公開前SEO Preflight

- title重複なし
- meta description主要ページ重複なし
- H1は原則1つ
- canonical自己参照
- sitemap収載URLと公開URL一致
- 404内部リンクなし
- beginner 01→05→diagnosisが一本道
- articleから最低1本は基礎/関連解説へリンク
- firm detailから必要な関連記事だけリンク
- HOLDプランを確定例にしない
- Affiliate URLを情報源リンクにしない
- 価格/キャンペーンを検索スニペットの恒常主役にしない
