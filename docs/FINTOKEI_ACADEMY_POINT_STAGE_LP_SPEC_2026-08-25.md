## 2. Fact Check Round 2｜反証・限定確認

### 50%OFF Academy benefit

Web上のFintokei公式FAQ検索では、本調査時点で50%OFFの対象条件・期限を確定できる公開ページを取得できなかった。

一方、ユーザーが2026-08-25時点のAcademy実画面で50%OFF特典を確認済み。

- `Academy内で50%OFF特典が表示されている`
- `対象プラン・取得条件・有効期限はアプリ内最新表示を確認`

禁止：
- すべてのChallengeが無条件50%OFF
- 永久50%OFF
- Academy登録だけで即時50%OFF

### 新しいSpecials

ユーザーがMyFintokei実画面で以下を確認：
- 100日間login
- 同一口座から3回Payout
- 損失日ゼロでChallenge / Phase合格
- 累計$10,000 payout
- 異なる3プランでPro口座到達
- Challenge失格 50XP

ただし記事執筆時点では新Specialが未解放でCountdown表示。

公式公開FAQではSpecial / Dailyという仕組み自体は確認できるが、上記の新規全タスクを公開Web一次情報として同時確認できていない。

したがって本文では：
`MyFintokei上に新しいスペシャルとして表示されている（記事執筆時点では未解放）`
とスコープを限定する。

「確定運用中」「現在獲得可能」とは書かない。

異なる3プランでPro口座到達については既存公式`Master Collector`で3プラン到達Specialが存在した事実も確認できるが、新表示の条件と完全同一とは断定しない。
