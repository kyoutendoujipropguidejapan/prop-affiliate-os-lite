## 0. Public wording under review

Current public surfaces use wording such as:

`一定の審査と損失ルールのもとで取引し、条件達成後に成果に応じた報酬を目指す仕組みです。多くの個人向けサービスでは、評価・資金提供口座ともシミュレーション環境が使われます。`

This is already safer than saying every Prop Firm provides real investment capital, but it is a general industry-level statement and therefore merits a service-nature audit.

## 4. Result

The public statement `多くの個人向けサービスでは...シミュレーション環境` is materially supportable as a broad description of multiple represented Firms.

However, the site should not let this general sentence replace Firm-specific service-nature disclosure.

Status:
`SUPPORTED_GENERIC_DESCRIPTION / WORDING_HARDENING_CANDIDATE`

Preferred future wording:

`当サイトで扱う多くのサービスでは、評価や報酬算定にシミュレーション口座・仮想資金が使われます。サービスの法的・契約上の位置づけは各社で異なるため、個別ページでは各社Terms / FAQの説明に従います。`

This keeps the useful beginner explanation while preventing a universal legal/business-model claim.

## 5. Compliance boundary

Do not use generic beginner copy to claim:
- real investment capital is always provided
- the user is trading a live brokerage account
- a Firm is regulated/unregulated in Japan solely from this generic description
- payout/profit is guaranteed

Firm Detail must carry Firm-specific service-nature evidence.
