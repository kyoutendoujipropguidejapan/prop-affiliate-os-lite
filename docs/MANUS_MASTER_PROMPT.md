## サイトの中心思想

`見やすい → 少し分かる → 次が気になる → 自分で進みたくなる`

単なる情報量の多い比較サイトにしないでください。

初心者は最初から14社・65プランを全部比較しません。

公開構造は：

ファーム一覧
↓
そのファームのプラン一覧
↓
必要なプランだけ詳細

です。

内部ではプラン単位で細かく管理しますが、公開画面には一度に大量表示しません。

## 絶対ルール

- Affiliate有無を診断スコアに使わない
- コミッションを診断スコアに使わない
- クーポンや割引率を診断スコアに使わない
- 価格を診断スコアに使わない
- SourceHealthの競合を勝手に解決しない
- 公式情報同士が矛盾したら「確認中」にする
- 割引後価格を自動計算して公開しない
- 価格/特典をトップや基礎講座の主役にしない
- 「最強」「絶対」「今すぐ」「知らないと危険」など過度な煽りを使わない
- 既存成果を作り直さない

## 調査の出典

外部の事実を使う場合は出典を付けてください。

プロップファームのルールや価格など変更される情報は公式サイト/公式FAQ/規約を優先してください。

## GitHub OSS

必要な機能に既存OSSが使えるか調査する場合、候補は最大3件程度に絞ってください。

比較項目：

- License
- 最終更新
- 現在も保守されているか
- 導入難易度
- 依存の重さ
- モバイル適性
- 再利用できる部分
- 不要部分
- 既存サイトへのリスク

OSSを採用しないという判断も歓迎します。
