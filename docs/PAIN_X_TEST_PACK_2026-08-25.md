# Test A｜P001 海外Firmを信用してよいか

## A1 Fear

`プロップファームを初めて見る人が一番怖いのは、失格じゃなくて「この海外会社、本当に大丈夫なの？」だと思う。`

`ルールや割引を見る前に、運営歴・公式情報・日本人利用・出金の確認順を知っておいた方がいい。`

質問：
`初めて海外Propを見た時、何が一番不安でしたか？`

## A2 Recognition

`「日本語サイトがある＝日本人向けに安心」ではない。`

`私なら、利用可否→KYC→出金条件→ルール→日本人利用報告の順で見る。`

`皆さんは海外Firmで最初に何を確認しますか？`

## A3 Reframe

`安いかどうかより、「分からない時に確認できるか」の方が初心者には大事かもしれない。`

`プロップは買った後にルールを知ると遅い。`

CTAなし。

# Test B｜P007 再失格が怖い

## B1 Fear

`3回目のチャレンジを買う前に、2回失格した理由を言えますか？`

`原因が分からないまま次を買うと、Firmを変えても同じ失格を繰り返すことがあります。`

`再挑戦する前に何を見直していますか？`

## B2 Recognition

`「また失格したら今月だけで3万円。」`

`そう思いながら次のチャレンジを探している時ほど、必要なのは割引コードより失格理由の整理だと思う。`

`Daily？ Max Loss？ ロット？ メンタル？`

## B3 Reframe

`チャレンジ失格は「Firm選びを間違えた」で終わらせない方がいい。`

`自分の手法とDDルールが噛み合っていない可能性もある。`

`次の口座を買う前に、失格原因を1行で言える状態にする。`

CTAなし。

# Test C｜P016 出金申請が怖い

## C1 Fear

`合格より緊張するのが、最初の出金申請という人もいると思う。`

`利益はある。でも「申請した瞬間に何か違反を指摘されたら」と考えてボタンを押せない。`

`初回出金で一番不安だったのは何でしたか？`

## C2 Recognition

`利益が出ている＝今すぐ出金できる、ではない。`

`KYC、Profitable Days、Consistency、Buffer、Minimum Withdrawal。`

`この辺が曖昧なままだと、利益があっても不安になる。`

## C3 Reframe

`プロップで本当に確認したいのは「出金が早い会社」より、「自分が出金条件を満たしているか分かる会社」かもしれない。`

`速さより条件の透明性。`

CTAなし。

# Test D｜P019 日本人Payout Evidence

## D1 Fear

`海外で何千件出金されていると言われても、日本人の自分が同じように出金できるかは別の不安が残る。`

`日本人の利用例を見ると安心する人は多いのでしょうか？`

`皆さんは参加前に日本人の出金報告を探しますか？`

## D2 Recognition

`1人の大きな出金報告より、普通の日本人の複数の出金例を見たい。`

`私はこの感覚が日本市場ではかなり重要だと思っている。`

`実際どうですか？`

※これは市場仮説の検証投稿。事実として断定しない。

## D3 Reframe

`「有名インフルエンサーが出金した」より、`
`「複数の日本人が普通に使って出金した」方が信頼材料になる人もいる。`

`あなたはどちらを重視しますか？`

投票形式候補：
- 有名人1人の大きな実績
- 日本人複数人の実績
- 公式運営歴
- どれも必要

# Test E｜P025 古いレビュー問題

## E1 Fear

`プロップのレビューで怖いのは、内容が間違っていることより「正しかったけど古い」こと。`

`Daily Loss、Payout、News、Legacy。半年で条件が変わることもある。`

`レビューの日付、見ていますか？`

## E2 Recognition

`「去年は良かったFirm」を今年も同じ条件だと思って買うのは危ない。`

`プロップはレビュー点数より、いつ確認した情報かが大事。`

`私は今後、変更履歴まで残したい。`

## E3 Reframe

`プロップの比較サイトに本当に必要なのは、ランキングよりChange Logかもしれない。`

`“今のルール”だけでなく、“いつ変わったか”まで分かる方が判断しやすい。`

質問：
`ルール変更履歴があれば見たいですか？`

# Winning rule

初期判定は絶対閾値ではなく、本人アカウントの通常投稿baseline比で見る。

WIN候補：

- Repliesが通常比で明確に高い
- Bookmark率が高い
- コメントに具体的な自分語りが複数出る
- 同じ悩みが別表現で繰り返される

HOLD：

- Likeは付くが自分語りが出ない
- 共感だけで次の疑問につながらない

REJECT候補：

- 角度を変えて2回試しても反応が弱い

WIN後：

X長文 → 図解 → Shorts → Article → 歩き方導線。

商品CTAは最後。
