# 12. X初期テスト設計

各Painは最低3角度でテストする。

- Fear：何を失うか
- Recognition：本人が実際に考えている言葉
- Reframe：一般的な考え方を逆転する

例 P007：

A Fear：`3回目のチャレンジを買う前に、2回失格した理由を言えますか？`
B Recognition：`また失格したら今月だけで3万円。だから次を買う前に止まってほしい。`
C Reframe：`失格した直後に必要なのは次の割引コードではなく、失格理由の特定です。`

評価項目：

- impressions
- likesよりReplies / Bookmarks / Profile clicks / Site clicksを重視
- comment内の生の言葉を新Painへ追加
- 反応良 → Thread / Graphic / Shorts / Article
- 反応弱 → angle変更後1回再試験。それでも弱ければHold
